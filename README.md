# astro-stacker
Web app to calibrate, register, and stack .fits files hosted on a NAS while running in a docker container on that NAS.

A minimal, self-hosted tool that wraps [Siril](https://siril.org/) for astrophotography calibration, registration, and stacking. Point it at a night (or several) of light frames plus your darks/flats/biases, review frame quality with a human in the loop, and get back a single stacked `.fit` file. Everything downstream of that — stretching, color work, star removal — happens in other software; this tool deliberately stops at the raw stack rather than growing into a full processing workbench.

The workflow is four steps mirroring Siril's own OSC Multi-Night Stacking tool: **Stage** (symlink raw frames from a read-only captures directory into a project), **Masters** (build master bias/dark/flat), **Review** (per-frame FWHM/roundness/star-count/SNR stats with anomaly flagging, so bad subs can be excluded before stacking), and **Stack** (calibrate, register, and stack the surviving lights into the final result). Multiple nights merge automatically; each night gets its own master flat by default since dust and vignetting genuinely shift night to night, while bias/dark are shared across the whole project. The backend is FastAPI shelling out to `siril-cli` via Jinja2-templated `.ssf` scripts, with a small in-memory job manager for the long-running stack/masters jobs and a plain HTML/CSS/JS frontend (no build step, no framework). The active-jobs panel tracks work across every project at once, so a stack running in one project stays visible while you're staged into a different one.

Currently developed against a long-lived dev container with the app bind-mounted for live reload; a standalone production `Dockerfile` now also exists (builds and runs against the same `/data`/`/captures` mounts, no bind-mount or reload) as prep for packaging this onto UnRAID.
