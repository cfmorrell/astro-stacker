advanced options
Star detection threshold (σ) controls how bright a spot must be, relative to the background noise, to count as a star. Lower finds more (fainter) stars but also more false positives from noise.

Bin factor downsamples each frame before measuring it (4 = average every 4×4 block into one pixel). Higher is faster but less precise — FWHM/star detection get coarser and small anomalies can be missed entirely. 4 is a good default for a quick review; drop to 1 (full resolution, slower) if you suspect subtle issues aren't showing up.
